Create API Key

Create one named API key. The secret will be shown once after creation.
API Key Name
Use a clear name that describes the integration or system using this key.
API Version
The key is bound to one API version. The latest version is selected by default, while older versions remain selectable for existing integrations.
Environment
Choose whether this key is used for production traffic or testing integrations.
Expiry
A defined expiry supports key rotation and reminder handling before access is interrupted.

Add IP Range

Define an allowed IP range for this API key. Requests from outside the configured range will be rejected.
